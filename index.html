Ghid Rapid pentru Echipa de Proiect

1. Cum adăugați cele 20 de poze și 20 de fișiere audio (.mp3)

Creați un folder assets/ lângă index.html, puneți pozele (ex: foto-01.jpg ... foto-20.jpg) și audio-urile (audio-01.mp3 ... audio-20.mp3), apoi actualizați câmpurile image și audioUrl în EXHIBITS_DATA.

2. Cum adăugați clipurile Video & Animațiile „Ion”

Încărcați clipurile pe YouTube (ca Unlisted / Nelistat) și treceți codul video de după ?v= în câmpul youtubeId din CINEMA_DATA.

3. Publicare gratuită „pe vecie” (GitHub Pages / Vercel)

Încărcați index.html și folderul assets/ într-un repository GitHub și activați GitHub Pages (sau conectați repo-ul pe Vercel). Link-ul va fi gratuit și accesibil permanent de pe orice telefon, iar opțional puteți conecta un domeniu .ro.

4. Arhivarea concursului după ziua expoziției

La finalul zilei de expoziție, debifați „Mod Ziua Evenimentului (Concurs Activ)” din subsolul paginii — setarea se salvează automat în browser și ascunde concursul.
